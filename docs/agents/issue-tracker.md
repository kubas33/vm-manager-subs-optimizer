# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List and filter issues with `gh issue list`.
- Comment with `gh issue comment <number>`.
- Apply or remove labels with `gh issue edit <number>`.
- Close an issue with `gh issue close <number>`.

Infer the repository from the configured Git remote.

## Skill mappings

- "Publish to the issue tracker" means creating a GitHub issue.
- "Fetch the relevant ticket" means reading the GitHub issue and its comments.
